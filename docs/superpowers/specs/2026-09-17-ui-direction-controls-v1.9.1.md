# V1.9.1 界面与方向测试控制设计

## 已确认需求

- “系统全局操作与测试报告导出”区域的标题、分区标签、按钮和复选框需要更大的字体与匹配的控件尺寸。
- 原始串口实时信息流从 SNR 表格页迁移到独立主标签页，保留暂停滚动、协议过滤和清空预览能力。
- 串口 2、串口 3 的四个方向各自拥有“启动、暂停、继续、终止”四个独立按钮。
- 暂停后停止累计时长和统计，继续后从原累计值恢复；终止后保留数据用于报表，但不可继续。
- “重新测试”清空该串口全部四个方向的数据和 ENU 快照，并恢复初始状态。
- 同一串口同一时刻只允许一个方向运行；启动另一个方向时自动暂停当前方向。两个串口之间互不影响。
- 三路 ENU 继续使用各自独立的参考点，本次不得改变 ENU 基准逻辑。
- 版本升级为 1.9.1，重新生成单文件 EXE、校验哈希并更新 Git 标签。

## 状态模型

每个方向采用 `idle -> running -> paused -> running` 和 `running/paused -> terminated` 状态转换。终止状态只允许通过“重新测试”回到 `idle`。按钮可用性由状态统一刷新，避免多个按钮触发同一切换函数造成歧义。
